# サッカーボール

[README に戻る](../README.md) · 日本語 · [English](soccer-balls.md)

このパッケージは 21 種類のサッカーボールを描きます。すべて立体（3D）で、`ballFrame` で回転し、継ぎ目は球面に沿っています。どのパネル構成も、多面体や曲線から計算して作ったもので、特定のメーカーや大会のボール、模様、グラフィックスは使っていません。出典と導き方は [references.md](references.md#soccer-balls)（英語）にあります。

これに、赤い `ball:soccer-colour`（六角形ごとに三角形が入ったボール）、`ball:futsal`、`ball:beach-soccer` を加えて 21 種類です。色違いは、スカッシュボールの点の色やクリケットボールの色と同じように、それぞれ独立した id にしてあります。ギャラリーにもレジストリにも 1 つずつ載せるためです。`tint` はオレンジ色や黄色を置き換え、`accent` は暗い色のパネルを置き換えます。白黒のボールは白い地に描いてあり、`tint` は暗い色のパネルを置き換えます。

```js
import { renderEmblem } from "@johnmorrisdotca/dougu-sports";
import { ballFrame } from "@johnmorrisdotca/dougu-sports/turn";

console.log(renderEmblem("ball:soccer-26", { size: 64 }).includes("<title>Soccer ball, 26 panels</title>")); // true
console.log(renderEmblem("ball:soccer-14-orange", { tint: "#e8f21c" }).includes("#e8f21c")); // true
console.log(ballFrame("ball:soccer-12", { yaw: 360 }) === ballFrame("ball:soccer-12", { yaw: 0 })); // true
```

## パネルの構成

パネルはどれも、球面上の単位ベクトルを環状に並べたものです。2 つの頂点をつなぐ辺は球面に沿って（球面線形補間で）描くので、空気を入れたボールのようにパネルがふくらんで見えます。コードは `src/emblems/ball/ball.tilings.ts`（球面の分割）と `ball.soccer.panels.ts`（ボール）にあり、`test/ball.test.ts` が各構成の頂点・辺・面の数を数えて確かめます。

- **32 枚貼り**（`ball:soccer`）：切頂二十面体。五角形 12 枚と六角形 20 枚で、頂点は 60 個、辺は 90 本です。
- **26 枚貼り**（`ball:soccer-26`）：斜方立方八面体。24 個の頂点は、(±1, ±1, ±(1 + √2)) の成分を並べ替えたものです。26 の面は、立方体の頂点の方向にある三角形 8 枚（暗い色）、立方体の面の方向にある正方形 6 枚（中間の色）、立方体の辺の方向にある正方形 12 枚（明るい色）で、辺は 48 本です。
- **18 枚貼り**（`ball:soccer-18`）：立方体の 6 つの面を、それぞれ辺から 3 分の 1 のところに引いた 2 本の線で区切り、3 本の帯にしたものです。各面を中心から球面に投影するので、継ぎ目はすべて大円の弧になり、隣り合う面の帯は互いに直角に走ります。バレーボールと同じ構成で、色だけがサッカーボール用です。
- **14 枚貼り**（`ball:soccer-14`）：切頂立方体と同じつながり方で、三角形 8 枚と八角形 6 枚です。頂点は (±ξ, ±1, ±1) の成分を並べ替えたもので、ξ = 0.42 とします（一様な切頂立方体（半正多面体）の ξ = √2 − 1 ≈ 0.414 にほぼ等しい値です）。八角形どうしが接する 12 本の辺を、それぞれ S 字に曲げます。大円の弧の上で、始点から t の割合だけ進んだ点を、球面に沿って横へ、弦（弧の両端を結ぶ線分）の長さ × 0.2 × sin(2πt) × (0.5 + 0.5 sin(πt)) だけずらします。この曲線は、辺の中点を中心に半回転しても同じ形になります。そのため、12 本の S 字、6 枚の八角形、8 枚の三角形は、立方体の 24 通りの回転対称をすべて保ち、鏡映対称は失います（つまり、このパネル構成には右巻き・左巻きがあります）。八角形は、三角形に接する 4 辺が直線で、残りの 4 辺が S 字になり、プロペラの形になります。向かい合うプロペラの 3 組は、それぞれ別の色調で描きます。
- **12 枚貼り**（`ball:soccer-12`）：正十二面体。20 個の頂点は (±1, ±1, ±1) と、(0, ±1/φ, ±φ) の座標の巡回置換です。12 枚の五角形は、(±1, 0, ±φ) とその巡回置換の方向にあります。接する五角形どうしが同じ組にならないように 4 つの組に分け（正二十面体の頂点の 4 色の塗り分けを、探索で求めました）、色調は 3 つで描きます（1 組が暗い色、1 組が中間の色、2 組が明るい色）。
- **6 枚貼り（熱接着）**（`ball:soccer-6`）：このパッケージ独自のデザインで、縫い目はありません（熱接着、サーマルボンディング）。6 枚の細長いパネル（ゴア）は、それぞれ、極から極へ走る 2 本の継ぎ目にはさまれています。継ぎ目は、極から極までの間に経度で 180° ねじれます（経度 = 360° × i / 6 + 90° × 緯度 / 90°）。継ぎ目は長くて浅い溝のようで、表面はなめらかで、シボ（表面の細かな凹凸）は他のボールより細かくしてあります。極はボールの回転軸から 28° 傾けてあるので、回転しているボールでも、すべての継ぎ目が上の 1 点に集まって見えることはありません。パネルは明るい色、中間の色、暗い色の順に並び、向かい合うパネルは同じ色になります。

## フットサルとビーチサッカー

| | フットサル（`ball:futsal`） | ビーチサッカー（`ball:beach-soccer`） |
| --- | --- | --- |
| 規則 | フットサル競技規則 2025/26、第 2 条「ボール」、1 項 | ビーチサッカー競技規則 2024-25、第 2 条「ボール」、1 項 |
| 号数 | 4 号 | 5 号 |
| 円周 | 62〜64 cm（描画は 63 cm、直径 200.5 mm） | 68〜70 cm（描画は 69 cm、直径 219.6 mm） |
| 試合開始時の重さ | 400〜440 g | 400〜440 g |
| 海面での空気圧 | 0.6〜0.9 気圧（600〜900 g/cm²） | 0.4〜0.6 気圧（400〜600 g/cm²） |
| 弾み | 2 m から落としたときの最初のバウンド：50〜65 cm（低い） | 定めなし |
| 描画 | 32 枚貼り。明るい青と白で、12 枚の五角形それぞれに小さな黄色の五角形が入る。つや消しで、表面にシボがある | 14 枚貼りのプロペラ形。黄色、オレンジ、青で、三角形は濃紺 |

大きさは `emblemInfo(id).size` にあり、規則は `size.rule`、そのほかは `size.note` に書いてあります。`lineup` は、フットサルのボールを 11 人制のボールより小さく描き、`test/proportions.test.ts` は、これらのボールすべてが規則の大きさに対して誤差 2% 以内であることを確かめます。競技規則は、年少者などのカテゴリーに合わせて、各協会がボールの大きさ・重さ・材質を変えることを認めています。ここに載せた数値は、通常の試合について規則が定める値です。11 人制のボールは、円周 68〜70 cm、重さ 410〜450 g です（IFAB 競技規則 第 2 条）。

## 色違い

ウィンターオレンジは `#ff6a13` で、雪の上や暗がりでも目立つ明るいオレンジ色です。蛍光イエローは `#e8f21c` です。どちらも、白黒のボールで暗い色のパネルになっている部分は暗い色（`#1e2025`）になり、中間の色のパネルになっている部分は、オレンジまたは黄色の明るい色調になります。ほかの点は白黒のボールと同じなので、大きさも規則も同じです。
