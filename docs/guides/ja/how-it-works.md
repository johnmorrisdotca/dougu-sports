エンブレムは、データと関数です。データ（輪郭、パネル、図形）は自分のモジュールにあり、関数がそれをSVGの文字にします。何も取ってこず、画像もフォントもスタイルシートもついてきません。

## 純粋で小さい

[renderEmblem](api:renderEmblem) は純粋です。同じ引数なら同じ文字列になります。1つだけバンドルしたエンブレムは、自分のデータと必要な小さな描画部分だけを持ちます。カップ1つがほしいページは、カップ1つ分だけを払います。

## 必要なときに描く

止まったエンブレムは1回だけ描きます。回っているものは、角度が変わったときに、1フレームに多くて1回だけ描き直します。回転はふつうのSVGで、WebGL ではありません。グラフィックスのコンテキストも、canvas も、テクスチャーもありません。要素は、画面の外にある間とタブが隠れている間は何も描きません。動きを減らす設定の人には `autoplay` は始まりません。

## 本当の穴、うそのない面

穴のあるボール（ピックルボール、練習用の野球ボール）の穴は本物です。手前の穴は殻から切り抜かれ、手前と奥の穴が重なると向こうのページが見えます。平らなものには縁と裏があります。メダルはコインのように裏返ります。

## 事実から描く

大きさはルールブックの大きさで、どのルールかは各エンブレムの情報（[emblemInfo](api:emblemInfo)）に書いてあります。作品のコピーやなぞり描きはせず、ブランド、リーグ、スポンサーのマークも描きません。本物のトロフィーは、公開されている説明と、見て確かめた写真から描いています。

## `style` ではなく `variant` の理由

`style` は本物の HTML 属性（インライン CSS）なので、フレームワークは CSS として読み、React は文字列を受け付けません。そのため、要素の見た目は `variant` です。
