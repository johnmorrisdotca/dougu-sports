ホッケーのパックは加硫した黒いゴムでできていて、記念品には天面に印刷をしたものがあります。旗、名前、背番号、サインなど、競技の道具の中でもとくに印刷の多いものです。このパッケージでは 8 種類を描きます。どれも立体（3D）で、`emblemFrame` と `ballFrame` で回転します。形は `ball:puck` と同じパック（直径 76.2 mm、厚さ 25.4 mm、比は 1 対 3、縁には滑り止めの溝）で、その天面に、パック自身の回転にあわせて印刷をのせています。パックを傾けると印刷は縮んで見え、パックと一緒に回り、天面が裏を向くと見えなくなります（底は無地のゴムです）。回すと、縁の溝も見えます。

面にあるものはすべて独自の絵です。独自のメープルの葉、独自の旗、独自の幅広の文字（`src/emblems/ball/ball.letters.ts` の線で描いた文字で、フォントファイルは使いません）、架空の名前と背番号、そして架空のサインです。チームやリーグのロゴ、ロゴタイプ、メーカーの印は使っていません。輪の文字も、ふつうの説明の言葉（`CANADA · ICE HOCKEY`、`SOUVENIR PUCK`）だけです。

## id 一覧

| id | 印刷されているもの |
| --- | --- |
| `puck:canada` | カナダ風の旗（赤・白・赤、中央に葉）と、その下の幅広の文字 CANADA。白い面を、文字の入った赤い輪が囲む |
| `puck:canada-red` | 赤い面に大きな白いメープルの葉とその下の CANADA。文字の入った暗い輪が囲む |
| `puck:canada-white` | 白い面に、旗にならった左右の赤い帯、大きな赤い葉、その下の CANADA |
| `puck:usa` | 星と縞模様の円盤の上に大きく書いた USA。文字の入った紺の輪が囲む |
| `puck:usa-navy` | 紺の面に、白い細線にはさまれた赤い輪、5 つの星、大きな白い USA の文字 |
| `puck:player` | ジャージのように、輪に沿った架空の姓（`MORRIS`）、大きな背番号（`23`）、金色の輪 |
| `puck:signed` | 紺のパックに、金色のマーカーで書いたような架空のサイン |
| `puck:souvenir` | 汎用のパック。クリーム色の面、好きな文字を入れた紺の輪、星（または自分で用意した絵）、その下の文字 |

パックは 1 つのモジュール `@johnmorrisdotca/dougu-sports/ball/ball.puck.print` にまとまっていて、メインエントリからは `PUCK_CANADA`、`PUCK_CANADA_RED`、`PUCK_CANADA_WHITE`、`PUCK_USA`、`PUCK_USA_NAVY`、`PUCK_PLAYER`、`PUCK_SIGNED`、`PUCK_SOUVENIR` として取り出せます。`PUCK_IDS` が id の一覧で、`isBallId`、`ballFrame`、`lineup` には、ほかのボールと同じように渡せます。

## `face` オプション

どのパックも `face` を受け取り、もともとの印刷の一部を置き換えられます。`ball:puck` に `face` を渡すと、その `face` つきの `puck:souvenir` として描かれます（`face` がなければ、ふつうのパックのままです）。

| フィールド | 働き |
| --- | --- |
| `design` | 出発点にするデザイン：`canada`、`canada-red`、`canada-white`、`usa`、`usa-navy`、`player`、`souvenir`。パックにはそれぞれ自分のデザインがありますが、これで差し替えられるので、`puck:souvenir` でもどれにでもなります |
| `image` | 任意の SVG（ロゴや紋章）。先に安全な形に直してから中央にはめ、デザインの絵の代わりに置きます |
| `emblem` | dougu のエンブレムの id（`"trophy:cup"`）。中央に小さく描きます。`renderEmblem`、`emblemFrame`、`ballFrame` が解決します。パックのモジュールだけを読み込んだ場合は `image` を渡します |
| `flag` | 国コード。`"ca"` と `"us"` はこのパッケージが描き、それ以外は呼び出しで渡す `flags` オプション（下記）が必要です |
| `text` | 絵の下の文字（`"CANADA"`）。1 行、24 文字まで |
| `ringText` | 縁に沿った文字。文字列（上側）、2 要素の配列 `[上, 下]`、または `false`（輪なし）。1 行 32 文字まで |
| `number` | ジャージのような大きな数字。英数字で 3 文字まで |
| `name` | 輪に沿って並べる姓。14 文字まで |
| `signature` | 架空のサインのシード（数または任意の文字列）。`false` ならサインなし |
| `colors` | 名前で指定する `{ field, ring, ink, accent, signature }`、またはこの順の配列。色は `#rgb`、`#rrggbb`、`rgb()` で、それ以外は無視します |

`flags` は `face` のフィールドではなく、`face` や `size` などと並ぶ、呼び出しに渡すオプションです。taisen-brackets が受け取るのと同じ描画関数なので、hata をラップしたアダプターを 1 つ用意すれば、どのパッケージでも使えます。シグネチャは `flags(code, { shape: "round" | "square" | "rect", size, theme: "inherit" | "light" | "dark" }) => string | null | undefined` で、同期関数です（描画は渡されたオプションだけで決まる純粋関数で、hata の `flag()` は非同期のため、先に旗を読み込んでおき、`(code) => loaded[code]` を渡します）。パックは `"rect"` の旗を 120 ピクセルで要求し、`theme` には呼び出しの `theme` を渡します（`light` と `dark` はそのまま、`auto` と `inherit` は `inherit`）。返された SVG は `image` と同じく安全な形に直します。そのコードの旗がなく `null` または `undefined` を返したときは、組み込みの旗（なければ旗なし）になります。旗を返した場合は、組み込みの `"ca"` と `"us"` より優先されます。

使い方の例は [英語版](pucks.md#the-face-option) にあります。

## サイン

サインは、シード付きのペン（`src/emblems/ball/ball.signature.ts`）で描いたくねくねした線です。名と姓があり、それぞれが背の高いループのある頭文字と、ループのある山の連なりで、なめらかな 1 本の線でつながり、最後に下線が引かれます。同じシードなら、いつも同じ線になります。どのシードも実在の誰かの筆跡ではないので、サインのように見えても、誰のサインでもありません。`signature` には数、または任意の文字列（`"Ace"`）を渡せます。`false` か指定なしならサインは描きません。インクの色は `colors.signature` で、既定では暗いパックには金色、明るいパックには黒です。

## 文字

文字はフォントを使わない線です。1 つ 1 つの字は、高さ 90 の枠の中に引いた中心線で、senshu-jerseys のブロック体（同じ作者、同じライセンス）をもとに、ここでは幅広く、太く、少し前に傾けて描いています。1 行の文字は 1 本のパスなので、どこでも同じ見た目になり、数百バイトで済みます。輪の上では、文字は弧に沿って立ち、上側は外向き、下側は内向きに読めます。字形のない文字（日本語の名前や絵文字）は描きません。字形があるのは、英字の大文字 A～Z（小文字は大文字に、アクセント付きの字はアクセントのない字に置き換えます）、数字、そして `- . , ' / : & ·` です。

## 安全な画像

`image` や描画関数から来た旗は外部の SVG なので、いったん分解し、厳しい許可リスト（`src/emblems/ball/ball.image.ts`）にそって組み直します。残るのは図形、グループ、グラデーション、クリップパスだけで、属性も、絵に必要なものと、アドレス・実体参照・スクリプトを含められない値だけです。script、style、text、image、use、foreignObject、フィルター、リンク、イベントハンドラは、中身ごと取り除きます。`style="fill:red"` は `fill="red"` になります。id は、そのパック専用の接頭辞で付け替えるので、ページ内の 2 つのパックが互いのグラデーションを参照することはありません。文字、名前、色は、そのままマークアップに入れることはありません。文字は線になり、色として読めない値は無視します。

## 使っていないもの

どの印刷パックにも、国のホッケー連盟の、スケート選手と葉のロゴ、国の協会の盾、代表チームや連盟のロゴタイプ、メーカーの印、有名な試合の名前、実在の人物のサイン、実在の選手の名前は入っていません。国名、メープルの葉、旗は独自の絵で、`puck:player` の架空の名前と背番号は例にすぎません。

## 見てみる

`node scripts/emblem-sheet.mjs sheet.png puck: --turn` で、パックを 256、64、16 ピクセルで、明るい背景と暗い背景に、静止と回転で並べた一覧画像が描けます。デモには「Print a puck」の節があり、すべてのパックは[ギャラリー](https://johnmorrisdotca.github.io/dougu-sports/gallery.html)にもあります。
